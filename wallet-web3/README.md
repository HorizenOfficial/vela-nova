# Horizen Nova Web Wallet

This is a web wallet for the Horizen Nova Wallet.

## Dependencies

The project uses the Horizen CCE Typescript library (https://github.com/HorizenOfficial/horizen-cce-common-ts).
A copy of the compiled library is loaded from [lib/](lib/) folder.

To update it: follow build instructions from [/horizen-cce-common-ts](https://github.com/HorizenOfficial/horizen-cce-common-ts) and then copy here the dist/ artefacts (TODO: direct update from npm repository...)


## How to run

Execute the following command to run a demo server, then connect the browser to [http://localhost:3000/](http://localhost:3000/):

```
npx serve
```
